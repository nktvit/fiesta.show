# **StreamFiesta**

Angular 20 (standalone components, zone-based, Tailwind 3) movie/TV streaming
site, deployed on Vercel. `main` is the **production** branch — merging to it
deploys to fiesta.show.

## Setup

```bash
# Best option is bun (fewer dependency issues)
bun install
# or
npm install

# Start the dev server (http://localhost:4200)
npm start
```

`src/environments/environment.ts` is gitignored and generated by
`scripts/set-env.js` on `prebuild`. It only ever writes `OMDB_API_KEY`, from the
environment — so **a plain local checkout has no API keys**: TMDB and OMDB calls
401, every list renders empty, and search shows the not-found state. Supply the
keys yourself, or mock the API (see `tools/e2e/`) when working on UI.

## Scripts

| Command | What it does |
|---|---|
| `npm start` | dev server on :4200 |
| `npm run build` | builds `tv/` then the Angular app |
| `npm run watch` | development build, watched |
| `npm test` | Karma unit tests (add `--watch=false --browsers=ChromeHeadless` for CI) |
| `npm run eval:moderation` | comment-moderation evals |

`npm test` currently has **5 known failures** in `movie.service.spec.ts`, which
hardcodes an OMDB key not present in the local env. Pre-existing, unrelated to
app code.

## Serverless functions

`api/` holds the Vercel functions (`tmdb`, `omdb`, `movie`, `stream`, `subs`,
`likes`, `comments`, `suggestions`). **None of them run under `ng serve`** —
they return 500 locally, so the video player and likes/comments only work on a
deployment.
